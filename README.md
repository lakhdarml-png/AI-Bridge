# AI Bridge — الجسر الذكي

تطبيق Android شخصي لتنسيق التعاون اليدوي بين تطبيقي **ChatGPT** و **Grok** دون أي API أو سيرفر سحابي.

## الفكرة
- تكتب الرسالة مرة واحدة داخل AI Bridge.
- تنسخها وتفتح ChatGPT أو Grok.
- بعد الرد، تنسخ الرد وترجع هنا لاستلامه.
- التطبيق يحفظ السجل ويميز كل رد باسم المساعد بوضوح.
- تقدر ترسل الرد للمساعد الآخر بسهولة للمراجعة أو التطوير.

## طريقة الاستخدام
1. اكتب الرسالة أو تعليمات الجولة في الحقل.
2. اضغط «نسخ النص وفتح ChatGPT» أو «نسخ النص وفتح Grok»، ثم الصق النص وأرسله داخل التطبيق الذي فتح.
3. انسخ رد المساعد من تطبيقه.
4. ارجع إلى AI Bridge واضغط «استلام آخر رد...» الخاص بالمساعد. يحفظ التطبيق الرد في سجل الجلسة ويجهز تعليمات مراجعة.
5. انقل النص إلى المساعد الآخر. كرر الجولة حسب الحاجة.

## حدود واضحة
- لا يقرأ التطبيق محادثات التطبيقات الأخرى تلقائيًا؛ يجب نسخ الرد ثم استلامه داخل الجسر.
- لا يرسل التطبيق رسائل نيابة عن المستخدم.
- لا يحتاج إلى خدمة إمكانية الوصول أو API key أو خادم خارجي.
- سجل الجلسة الحالي داخل الذاكرة أثناء فتح التطبيق فقط.

## البناء
من GitHub Actions افتح workflow **Build Debug APK**، ثم نزّل الـ artifact المسمى `ai-bridge-debug` بعد نجاح البناء.
